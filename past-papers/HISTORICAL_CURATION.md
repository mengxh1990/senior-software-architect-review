# 2009–2017 历史题库处理与复核

## 结论与适用范围

老年份不等于知识失效。此处按训练收益缩减范围：综合知识从 2018 年起训练；2009–2017 的案例、论文只保留经小问复核的经典内容。删题不代表相应技术在现行大纲中被删除。

保留标准：主要小问考查可迁移的架构/工程基础，有可核对的题干和材料，不依赖特定旧版本结论；标签按实际考查内容确定。行业背景本身不决定去留。删除标准：具体旧标准/框架细节、材料或参考结论不可靠，以及本轮明确缩减的非核心专题。

原题号和保留题内容不重编号。筛选后旧卷是专题选题，不能声称是完整年份模考。原始 PDF 留在原目录；删除的 Git 跟踪内容可从版本历史恢复。私人历史作答不删除、不因题源变化重新判分。

## 实施步骤

1. 阅读旧案例 45 题、论文 36 题的背景和小问，列出保留/移除理由。
2. 删除 9 份综合卷，移除其批量导入和题组映射入口。
3. 案例题干版与参考答案版同步筛选；旧论文的参考要点显式分隔。
4. 修正保留题的标签；DFD 单列案例 14、设计模式单列案例 15，避免套入 UML 或微服务。
5. 同步索引、来源覆盖、校验基线和考频快照。旧精选数量不解释为历年考试概率。
6. 验证题号、正文标签、标签表和独立复核清单一致，检查资源链接、盲练/揭示答案和剩余题库。

## 复核结果

- 旧综合卷：删除 2009 下至 2017 下共 9 份；训练池仅保留 2018 年起的综合真题。
- 配套图片：删除 94 个已无当前正文引用的 Git 跟踪旧年份图片，仍被经典题使用的图片保留。
- 旧案例：保留 30/45 题，删除 15 题；保留题干版及对应参考答案。
- 旧论文：保留 28/36 题，删除 8 题；另有 3 个被误标为试题的参考要点标题归回正文。
- 复核日期：2026-09-25。机器可读清单见 `scripts/historical_subjective_review.json`。
- 本次只筛选历史年份，不调整考生已选择的个人赛道。旧题可用于专题补练；近期考频以近期卷另行统计，不能把精选后的占比当作考频。

## 标签验收

`python3 scripts/tag_case_essay.py --check` 同时校验原题号、正文标签、标签表、原卷/答案版一致性及复核清单。关键词检查只防止已审题目发生明显错位，不能代替人工语义复核。

典型纠正：2009 二/2014 二是 DFD；2009 四是控制环路与面向对象风格；2010 二是分布式数据库，四是 ESB；2011 四是 REST，五是安全控制；2012 四是设计模式；2014 一是 MVC；2015 二是 UML；2016 一是风格比较与质量属性；2017 四是 ORM/数据访问层。2010 三、2012 二、2016 三论文属于缓存/持久层/数据访问层架构，不能当成 NoSQL 论文。
