# 案例分析 · 按年份真题

> 与 [`case-types/`](../case-types/) 的区别：这里按**年份**存原题与参考答案，那里按**题型**存套路与模拟题。
>
> 每道题标题下方都带一行 `> **题型**：案例 NN · …`，编号（案例含新增 14/15）对应 [`case-types/`](../case-types/) 的题型；标为 `案例 00` 的是尚未沉淀 playbook 的题型。
>
> **两种版本**：`<考期>-原卷.md`（2009 下–2017 下）是**题干与参考答案分离**的原卷，用于盲练，插图也是原卷插图；同考期不带后缀的文件是"答案详解"转录版，题干与答案混排，只用于**研读与作答后对答案**。训练统一走 [`scripts/paper_practice.py`](../../scripts/paper_practice.py)。

## 使用建议

- **必答题（试题一）** 历年集中在架构评估 / 质量属性，用 [case-types/01-architecture-evaluation.md](../case-types/01-architecture-evaluation.md) 的套路配合本目录原题；
- **选答题** 按自己项目熟悉的领域挑：数据库设计、微服务改造、消息缓存、嵌入式、安全；
- 2009–2022 的原题含参考答案，适合"先自己写、再对照"；回忆版年份（2024 上起）题面可能不完整，用于趋势判断；
- 配套训练节奏见 [CASE_SURVIVAL.md](../CASE_SURVIVAL.md)。

> 2009–2017 已按 [历史题复核](../HISTORICAL_CURATION.md) 筛选；用于专题训练，不能作为完整年份模考。
