## 使用建议

- **必答题（试题一）** 历年集中在架构评估 / 质量属性，用 [case-types/01-architecture-evaluation.md](../case-types/01-architecture-evaluation.md) 的套路配合本目录原题；
- **选答题** 按自己项目熟悉的领域挑：数据库设计、微服务改造、消息缓存、嵌入式、安全；
- 2009–2022 的原题含参考答案，适合"先自己写、再对照"；回忆版年份（2024 上起）题面可能不完整，用于趋势判断；
- 配套训练节奏见 [CASE_SURVIVAL.md](../CASE_SURVIVAL.md)。
